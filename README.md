# LoopFB and LoopNoFog

Roblox lighting script by romokaso

## Features
- FullBright with brightness slider
- NoFog removes all fog
- Fog Density control
- Time of Day loop
- 7 keybinds
- Dark and Light theme
- Save and Load settings

## How to use
Paste script into your executor and execute
